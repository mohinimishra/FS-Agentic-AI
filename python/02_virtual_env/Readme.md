Command to run Virtual env (Traditional way)

```py
python3 -m venev .venv
source .venv/bin/activate
```

To install package
```py
pip install flask
```


To install package from requirements.txt
```py
pip install -r requirements.txt
```

To deactivate virtual env
```py
deactivate
```
